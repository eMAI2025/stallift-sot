# WEB DECISIONS — CURRENT

## D-001 — Jeden design system
WWW, blog i konfigurator używają wspólnego headera, footera, typografii, tokenów kolorów, buttonów, light/dark i zasad responsywności.

## D-002 — Blog jako referencyjne wdrożenie
Najpierw domykany jest blog. Po akceptacji jego design system jest przenoszony na WWW, a następnie konfigurator.

## D-003 — Routing
- `/` firma
- `/konfig/` konfigurator
- `/blog/` publikacje

## D-004 — Lokalny silnik Excel
Wykonawcze arkusze Excel, wzory, algorytmy, ceny i logika obliczeń są LOCAL-ONLY. Zakaz publikacji w GitHub/WWW.

## D-005 — Public preview
Publiczne preview jest dopuszczalne. Repo wykonawcze WWW może pozostać publiczne.

## D-006 — SoT
Repo SoT powinno być PRIVATE, ponieważ ma przechowywać pełny kontekst decyzji i handoff między wątkami.

## D-007 — Blog home
Duży tytuł `PUBLIKACJE EKSPERCKIE`; bez identycznego małego powtórzenia. Autor domyślnie Paweł Strzelecki, ale edytowalny.

## D-008 — Author block
Opcjonalny blok autora: zdjęcie, krótki opis, LinkedIn, visibility toggle. Pełne doświadczenie zawodowe pozostaje na LinkedIn.

## D-009 — Cycle presentation
Jeden aktywny wariant na cykl: carousel OR collage OR graphical TOC. Nie kumulować trzech dużych prezentacji naraz.

## D-010 — Article grid
Admin może komponować wiersze 2/3/FEATURE. Wariant pojedynczy jest poziomy z wyborem strony grafiki.

## D-011 — Cover fit
Okładka publikacji ma być prezentowana w całości; brak domyślnego agresywnego crop.

## D-012 — Dark theme
Ciemny motyw: czerń/grafit, nie granat dominujący; subtelne warstwy, bez neonu.

## D-013 — Header
Sticky. Wordmark, trzy główne sekcje, theme, Facebook, LinkedIn, konto. Buttony z subtelnym odbiciem i active `#005195`.

## D-014 — Account routing
Niezalogowany -> login. Zalogowany czytelnik -> konto. Admin -> panel admin.

## D-015 — Comments
Zalogowany czytelnik komentuje bez dodatkowej weryfikacji. Gość może komentować po prostej weryfikacji e-mail bez tworzenia konta.

## D-016 — Footer
Dane firmy + polityki + dyskretna Strefa autoryzowana. Bez publicznego numeru wersji. Bez powtórzenia całej nawigacji headera.

## D-017 — Corporate website
Strona firmowa docelowo one-page dla podstawowych sekcji. Portfolio może być osobnym widokiem z powodu ciężaru multimediów.
