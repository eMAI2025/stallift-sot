# LOCAL-ONLY / PUBLIC BOUNDARY

## MUST STAY LOCAL
- wykonawcze kalkulatory Excel;
- formuły i makra;
- ceny i cenniki wewnętrzne;
- algorytmy obliczeniowe;
- prywatne dane dostępowe;
- sekrety API/SMTP;
- niewydane know-how konstrukcyjne lub handlowe.

## MAY BE PUBLIC
- publiczny frontend;
- opublikowane artykuły;
- zaakceptowane grafiki;
- publiczny konfigurator UI;
- publiczne portfolio;
- publiczne dane firmy;
- robots/sitemap/SEO metadata.

## SoT
SoT przechowuje decyzje, architekturę i status, ale nie kopiuje lokalnego silnika Excel. Docelowo repo SoT powinno mieć visibility PRIVATE.
