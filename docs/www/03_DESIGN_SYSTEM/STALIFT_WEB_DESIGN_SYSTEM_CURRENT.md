# StalLIFT Web Design System — Current Direction

## Brand
Primary blue: `#005195`.
Use metallic/technical character without gaming neon.

## Themes
### Light
- off-white / white surfaces;
- graphite text;
- blue accent;
- clear borders and restrained shadows.

### Dark
- near-black / graphite base;
- avoid dominant navy panels;
- layered surfaces via small luminance changes;
- blue only as accent;
- no large neon glow.

## Header
Sticky.
Order:
1. StalLIFT wordmark
2. StalLIFT
3. Kalkulator
4. Blog/Publikacje
5. theme toggle
6. Facebook
7. LinkedIn
8. account

Navigation buttons:
- same family in light/dark;
- reflective treatment allowed;
- subtle hover;
- active `#005195`;
- focus state independent from hover.

## Footer
- round mark + wordmark;
- corporate/contact block;
- Privacy / Terms / Cookies;
- subtle Authorized Zone;
- no public build/version number.

## Responsive
Single responsive system. No separate desktop/mobile implementation forks.
Mobile must not require hover for essential information.

## Article cards
- covers visible in full;
- part label + complete title always visible;
- minor description may reveal on hover/focus desktop;
- 2/3/feature layouts;
- one-card layout = horizontal editorial composition.

## Motion
Motion must support navigation, not decoration.
Carousel: drag/swipe/manual; no jitter, no unnecessary flip, respect reduced motion.
