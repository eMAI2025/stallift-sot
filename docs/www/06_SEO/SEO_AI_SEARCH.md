# SEO / AI Search requirements

Required production features:
- canonical URLs;
- dynamic `robots.txt`;
- dynamic `sitemap.xml`;
- real `lastmod`;
- per-page title and meta description;
- Open Graph/social preview;
- JSON-LD: WebSite, Organization, Blog, BlogPosting, BreadcrumbList;
- `datePublished` and `dateModified`;
- RSS or Atom feed;
- `llms.txt`;
- OAI-SearchBot allowed;
- GPTBot disallowed;
- IndexNow support;
- SEO fields editable in admin with safe automatic defaults.

Canonical routing:
- `https://stallift.com/`
- `https://stallift.com/konfig/`
- `https://stallift.com/blog/`

Principle: short, stable URLs and strong internal linking. Do not invent production URLs before routing is confirmed.
